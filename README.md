Smart Saqya SCADA System
نظام ري ذكي لإدارة المياه في الزراعة
نظرة عامة
Smart Saqya هو نظام ري ذكي يعتمد على تقنيات SCADA وإنترنت الأشياء (IoT) بهدف مراقبة وتحكم لحظي في أنظمة الري الزراعي.
يهدف النظام إلى تقليل استهلاك المياه، تحسين كفاءة الري، وتقليل التدخل البشري في إدارة المزارع، خاصة في المناطق الصحراوية مثل الوادي الجديد.
فكرة المشروع
الفكرة الأساسية هي تحويل نظام الري التقليدي إلى نظام ذكي يعتمد على البيانات الفعلية القادمة من الحساسات، بحيث يتم تشغيل أو إيقاف الري تلقائيًا بناءً على حالة التربة ودرجة الحرارة ومستوى المياه.
المشكلة
الاعتماد على الري التقليدي الثابت
هدر كبير في المياه الجوفية
تشغيل المضخات بدون احتياج فعلي
ضعف التحكم في توزيع المياه
ارتفاع تكلفة التشغيل والصيانة
الحل
نظام Smart Saqya يقدم حل متكامل يعتمد على:
قراءة بيانات التربة والمياه
تحليل البيانات بشكل لحظي
اتخاذ قرار تشغيل أو إيقاف الري تلقائيًا
تقسيم الأرض إلى مناطق (Zones) للتحكم الدقيق
نظام إنذار عند وجود أي خطر


مكونات النظام
البرمجيات
Python (Flask)
HTML / CSS / JavaScript
Chart.js
REST API (JSON)
المكونات المادية
Raspberry Pi 4 (وحدة التحكم الرئيسية)
حساسات رطوبة التربة (Soil Moisture Sensors)
حساس درجة الحرارة (DHT22)
حساس مستوى المياه (Water Level Sensor)
وحدة Relay للتحكم في المضخة
مصدر طاقة (Solar / Grid Hybrid)
أسلاك وتوصيلات
نظام الطاقة
النظام يعمل بنظام هجين:
يعمل بالطاقة الشمسية في النهار
يعمل بالكهرباء الحكومية في الليل
بدون بطاريات (تشغيل مباشر عبر إنفرتر)
طريقة عمل النظام
جمع البيانات من الحساسات
إرسال البيانات إلى وحدة التحكم
تحليل البيانات باستخدام خوارزمية بسيطة
اتخاذ قرار تشغيل أو إيقاف المضخة
إرسال الحالة إلى لوحة التحكم
تحديث البيانات بشكل لحظي
منطق التشغيل
النظام يدعم وضعين:
1. الوضع التلقائي (AUTO)
يقوم النظام بالتحكم الكامل في الري بناءً على البيانات.
2. الوضع اليدوي (MANUAL)
يسمح للمستخدم بالتحكم المباشر في تشغيل وإيقاف المضخة.
لوحة التحكم (Dashboard)
توفر لوحة التحكم:
عرض درجة الحرارة
عرض رطوبة التربة
عرض مستوى المياه
حالة تشغيل المضخة
التحكم في النظام (AUTO / MANUAL)
إدارة مناطق الري (Zones)
عرض بيانات لحظية
نظام الإنذار
يقوم النظام بإصدار تنبيهات في الحالات التالية:
انخفاض مستوى المياه
جفاف التربة
ارتفاع درجة الحرارة
البنية المعمارية (Architecture)
يتكون النظام من ثلاث طبقات:
طبقة الحساسات (Sensors Layer)
طبقة المعالجة (Raspberry Pi / Backend)
طبقة العرض (Web Dashboard)
Raspberry Pi Integration
تم تصميم النظام ليعمل مباشرة على Raspberry Pi كوحدة تحكم مركزية، حيث يقوم بـ:
قراءة البيانات
تشغيل منطق التحكم
التحكم في المضخة عبر Relay
إرسال البيانات إلى واجهة المستخدم
ملاحظة تقنية
النظام الحالي هو Prototype يعمل على Flask باستخدام بيانات محاكاة، لكنه مصمم ليتم نقله مباشرة إلى بيئة حقيقية دون تعديل في منطق التشغيل.
الهدف من المشروع
تقليل استهلاك المياه
تحسين كفاءة الري
تقليل التدخل البشري
دعم الزراعة الذكية في المناطق الصحراوية
القيمة المضافة
نظام SCADA مصغر منخفض التكلفة
قابل للتطبيق في المزارع الصغيرة والمتوسطة
يعمل بدون إنترنت
قابل للتطوير إلى نظام صناعي كامل
قابلية التوسع
يمكن تطوير النظام ليشمل:
تطبيق موبايل للتحكم
ذكاء اصطناعي للتنبؤ بالري
ربط سحابي (Cloud Integration)
دعم مزارع كبيرة متعددة المناطق
الخلاصة
Smart Saqya هو نظام متكامل لإدارة الري الزراعي يعتمد على البيانات والتحكم الذكي، ويهدف إلى تحسين استخدام المياه وتحويل الزراعة التقليدية إلى زراعة ذكية مستدامة.
